# 排版样张

这篇样张包含标题、表格、中文长段落和代码。把它和使用手册并排摆放，拖动分隔线，观察正文如何在更窄的空间里重新排布。

## 窄栏中的正文

阅读技术文档时，同一个屏幕常常需要放下一份 API 说明和一份实现笔记。每一栏都可以独立滚动。改变版式时，阅读器会尝试保持当前段落。

> 某些代码或表格的宽度大于视口。可以在代码块或表格内部横向滚动。

## 代码与表格

```ts
export function label(path: string): string {
  const parts = path.replaceAll('\\', '/').split('/')
  return parts.at(-1) || path
}

const message = '在窄分屏中，这一行可以通过代码块自身的横向滚动查看完整内容。'
```

| 对象 | 位置 | 记忆方式 | 恢复时机 |
| :--- | :--- | :--- | :--- |
| 文件夹 | 左侧文档库 | 路径与展开状态 | 启动工作台 |
| 标签 | 各自的阅读区 | 文档和正文锚点 | 返回标签 |
| 阅读主题 | 顶部设置 | 字号、行距与配色 | 同步到阅读窗口 |

## 再读一遍

可以把字号调大，再返回这里检查位置是否稳定。回到[使用手册](./起点.md#并排阅读)了解分屏操作。
