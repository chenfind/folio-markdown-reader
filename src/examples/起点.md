# 在文档之间从容切换

把散落在项目目录里的 Markdown 放到同一个文档库。从左侧打开手册、笔记和说明，在阅读区顺着目录往下看。遇到需要比较的内容，可以把两篇文章并排放着。

> 试试右上方的左右分屏，再从左侧打开「排版样张」。两侧可以分别滚动，各自记住读到的位置。

## 打开你的文档

用顶部的「打开文件夹」添加一个资料目录，再展开里面的子目录。你可以重复添加文件夹。单独打开的 Markdown 则会出现在「独立文件」里。

文件树按需展开，保留原来的目录层级。把鼠标停在同名标签上，可以查看路径。

## 并排阅读

| 你想做的事 | 操作 |
| :--- | :--- |
| 同时看两篇文档 | 点标签栏右侧的左右分屏，再选第二篇文档 |
| 对照同一篇的不同章节 | 创建分屏，分别在两栏定位到需要的段落 |
| 移到另一块屏幕 | 点「移到独立窗口」，或把标签拖出桌面窗口 |
| 专心读一篇长文 | 从顶部开启专注阅读，按 Esc 返回 |

## 按自己的节奏阅读

打开「阅读设置」，试试暖纸主题、较大的字号和更舒展的行距。调整窗口宽度时，阅读器会尽量留在原来的段落附近。

```ts
const reading = {
  theme: 'paper',
  fontSize: 17,
  lineHeight: 1.8,
}
```

## 接着上次读

切换文档后再回来，阅读器会找回当时的段落。哪怕调整了字号，或在原文件前面插入了几行，也可以尝试按章节和段落恢复位置。

想看看长代码和宽表格的效果，可以打开[排版样张](./排版样张.md#代码与表格)。
