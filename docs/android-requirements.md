# Android 端约定

本文件记录已确认的产品决策。开发 Android 功能、调整平台能力或重构阅读布局前，应先阅读本文件。

## 独立窗口

**Android 版不需要独立阅读窗口。**

Android 只使用应用内阅读区。创建原生独立窗口、拖出文档弹窗、移回主窗口、恢复独立窗口都属于 Windows 功能。Android 的 independentWindows 能力必须为 false，不能因为运行在 Tauri 原生环境中就启用桌面窗口功能。文件树、标签、正文链接的触屏操作不能触发独立窗口。

这个决定同样适用于手机和平板。以后若改变，需要先明确修改本约定和对应回归测试。

## 应用内分屏

保留两个阅读区，各自拥有文档、标签和阅读位置。

- 竖屏使用上下分屏，对应 column。
- 横屏使用左右分屏，对应 row。
- 方向随设备旋转自动适配，弹出输入法不会改变分屏方向。
- 旋转时保留两边的文档、当前标签、聚焦阅读区和阅读锚点。
- 单页模式旋转后重新分页，再恢复对应内容位置。
- Windows 继续允许用户手动选择上下或左右分屏。

不要只为调整方向销毁整个阅读会话。输入法弹出、系统分屏改变可用尺寸时，也需要验证布局和位置恢复。

## Git 克隆

保留远程只读连接。克隆必须由用户手动触发。

Android 克隆使用应用内置 Git 实现，不能要求设备预装 git 命令或 Termux。Windows 当前仍通过本机 Git 和它的凭据完成克隆。

Android 首版的任务规则如下。

1. 只保证前台克隆，不做后台持续克隆。
2. 每次任务在应用管理的独立临时目录执行。
3. 下载和检出全部成功后，才把仓库加入文档库。
4. 用户取消、网络中断或克隆失败时，先停止并确认任务退出。
5. 提供重新克隆入口。重试前删除该任务未完成的数据，然后从头克隆。
6. 只清理 Folio 为这次任务创建的临时目录。已有完整仓库、用户目录和其它任务不属于清理范围。
7. 清理失败时显示原因，不能在残留目录里直接重试。
8. 进程被系统终止后，下次启动自动清理应用管理的未完成临时目录，用户可以重新克隆。

首版优先 HTTPS 和令牌认证。任务进度、取消、失败原因和重试要有可见反馈。API 读取权限和 Git-over-HTTPS 克隆权限分别验证。SSH、LFS、子模块、后台任务不属于这轮基础重构的实现范围。

## 文件与凭据

本地文件通过 Android Storage Access Framework 授权访问。共享层使用稳定的文档 ID，原始 content URI 和持久授权由 Android 文件适配器管理。

尽量保留原位置读取的产品行为。仅授权单文件时，要明确处理相对图片和跨文件链接所需的目录授权。启动恢复、目录刷新、文件被移动及权限被撤销都需要有实际设备验证。

私库令牌由 Android 原生安全凭据适配器保存，不能使用 Windows Credential Manager，也不能将令牌写入 localStorage、仓库地址或普通文档配置。

## 当前状态

Android 预览版已接入 SAF 原位置读取、Keystore 加密令牌、JGit HTTPS 浅克隆、前台进度与取消清理、触屏布局和 Gradle APK 工程。独立窗口保持禁用。真机兼容性、不同文档提供器、企业私库和系统回收恢复仍需持续验证，构建成功不能代替这些验证。

## Android 验收

至少验证本地文档与远程文档阅读、分屏后双向旋转、单页模式重排、进程重建后的阅读位置、私库重新授权，以及克隆取消和失败重试。确认 Android 不显示或恢复任何独立窗口。

## 手机交互补充

手机端采用独立底部工具栏/面板方案，不照搬桌面栏位。交互控件、实际滚动、选择和系统手势优先于翻页；二元设置用 Switch，少量选择平铺。详细规则见 [手机阅读交互](mobile-interactions.md) 与仓库 [AGENTS.md](../AGENTS.md)。

## 仓库统一更新（0.2.3）
在线读取与本地克隆提供相同的配置、单独更新、全局更新入口，树中分别标记“在线”和“本地克隆”。不在启动时自动同步远程版本。普通 SAF 文件夹仅重读，不覆盖。

应用内克隆是以远程内容为准的离线副本，允许覆盖本地修改。更新或修改配置时先在独立临时目录下载新的浅克隆，验证阅读目录后再提升为完整快照；通过同步提交文档授权记录，将原 saf:/UUID 切换到新快照，保留文档地址和阅读位置。切换成功后才清理旧快照；失败、取消、进入后台时旧记录不变。重启清理未完成目录和未注册快照，不清理仍在注册记录中的完整仓库。旧版克隆通过已注册的私有目录及 Git origin 恢复来源，凭据仍从 Keystore 读取。

源码查看在应用内展示，不使用独立窗口。支持只读原文分页、滚动、搜索、复制，以及竖屏上下/横屏左右对照和双向位置同步。系统返回优先关闭上层确认框，再关闭源码。
