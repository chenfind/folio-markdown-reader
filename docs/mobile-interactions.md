# 手机阅读交互

## 页面结构
手机端使用独立的小屏布局，保留 Folio 的青绿色、纸张主题和正文排版语言。

- 顶部只放返回历史、当前文档与路径、文档列表入口。
- 底部常驻文档库、目录、分屏/合并、外观、更多五个触屏入口。
- 文档库用底部面板管理多个文件夹、仓库和单篇文档，提供打开文件夹/文件入口。
- 文档列表代替桌面横向标签条，支持切换、关闭及“关闭其它/左边/右边”菜单。
- 路径可以点击查看，逐级浏览并跳到同目录文档；目录对应当前聚焦阅读区。
- 分屏使用上下/左右自适应布局，每区显示文档标题和聚焦状态。合并时保留双方标签和阅读位置。
- 中间点按收起或显示工具；专注状态保留底部上一页、下一页和页码，不显示右下角工具悬浮按钮。可通过中间点按或系统返回退出专注阅读。
- 底部面板可点遮罩、关闭按钮、系统返回、Escape 或下拖标题/把手关闭。列表内部滚动不触发关闭。

## 翻页与内容交互
单页模式左滑下一页、右滑上一页；文档系列首尾可以连续跨文档，保持在当前标签。

优先级如下：
1. 链接、按钮、表单、可编辑区域、交互角色和 data-reader-interactive 组件。
2. 文本选择、长按、双指缩放，以及系统屏幕边缘手势。
3. 内容自身的实际滚动。
4. 未消费的阅读手势。

table、pre 和 img 不再仅按标签阻止翻页。表格/代码的实际溢出与 overflow 决定是否保留内部滚动；不溢出的表格、短代码和静态图片允许翻页。真实可滚动内容会标记并可用键盘聚焦。横向溢出的表格/代码保留原生横滑，即使到达内容边界，也不会突然把同一手势交给阅读器。

翻页手势要求明显的水平位移和方向优势，过滤过短、过慢、纵向、取消、多指与屏幕边缘起手。拖动后吞掉对应的合成点击，避免连续翻两页或误点链接；记录整个轨迹最大位移，返回起点也不能变成点按。

当前 Markdown 禁止原始 HTML。浏览器无法可靠推断任意第三方脚本所有事件监听器，所以自定义组件必须遵守显式交互标记契约，不能宣称对任意组件都百分之百自动识别。

桌面链接悬浮显示实际目标地址；手机长按链接显示地址预览，点击外部链接必须确认后才交给系统打开。长按移动、多指或取消时不弹出链接预览，正文与输入框保留系统选字、复制和粘贴菜单，不再在根界面统一阻止 contextmenu。

手机禁用 WebView 默认的蓝色点击高亮，使用主题色和轻微按压缩放反馈；减少动态效果时不缩放。桌面阅读容器不显示包围整区的焦点边框，按钮、输入框和可滚动内容仍保留键盘焦点提示。

## 设置
阅读模式、滑动翻页、点按翻页、新标签打开等二元状态使用 Switch；主题、动画和手机留白使用分段按钮/卡片。字号可一步加减，滑块保留微调。手机正文自动适应可用宽度，通过页面留白控制行宽；桌面保留正文宽度设置。

恢复默认会更新全部设置。旧版本配置会补齐新增字段，保留原有主题、字号和阅读模式。

移出文档库默认需要确认，提示不会删除原文件；可以在确认框选中“以后不再提醒”，也可以在设置中重新打开“移出文档库前确认”。取消移除不改变这个设置，恢复默认会重新启用确认。

文档库中的远程连接提供可见的“修改仓库配置”按钮，两端均可修改地址、分支/标签、目录和令牌；空令牌复用已保存凭据。全局更新重新解析配置指定的分支或标签提交，再刷新目录和正文；固定标签不会自动切换到其他分支，本地克隆同样参与单独和全局更新，先准备新快照再替换，失败保留旧副本；普通本地文件夹仅重读。HTTP 请求要求重新验证缓存，Android 同时禁用 HttpURLConnection 缓存。并发刷新保留用户发起的远程同步请求。

## 回归
运行 npm test 和 npm run build。

启动预览：
~~~sh
node node_modules/vite/bin/vite.js --host=127.0.0.1 --port=1422
~~~

另一个终端运行：
~~~sh
npm run test:mobile
~~~

测试使用本机 Chrome 的 Headless 模式和浏览器触摸输入，不安装额外浏览器测试依赖。可用 CHROME_BIN 指定浏览器路径，FOLIO_TEST_URL 指定已启动的预览地址，FOLIO_TEST_OUTPUT 指定截图目录；默认截图写入忽略的 test-results。

测试中的 Android 文件/仓库桥接是可控假数据，用于验证共享 UI；不能替代 SAF、Keystore、企业私库或厂商设备的真机测试。覆盖普通/可滚动表格、短代码、静态图片、链接与控件、长按、多指、左右手势、跨文档、设置、目录、标签、分屏旋转和合并。

## 源码与本地克隆更新（0.2.3）
“更多”提供低频的“查看 Markdown 源码”，默认分页，独立记忆分页/滚动选择，不改变正文阅读设置。支持搜索、选字和复制，无编辑能力。对照阅读竖屏上下、横屏左右，切换方向保留源码内容位置；同步位置开关默认开启，按解析器源码行号与正文块映射双向跟随，程序产生的跟随事件不反向驱动。关闭源码保留底层标签和阅读位置；Escape、关闭按钮和系统返回均可退出，焦点返回原入口。分页源码通过按钮或键盘翻页，不接管正文的翻页手势。

树根仓库行显示“本地克隆”或“在线”，下方提供带文字的单独更新按钮，设置图标对两类来源可见。更新本地副本时显示进度，Android 可取消；全局更新串行处理本地快照，进入后台后不启动后续本地下载。Windows 旧版克隆和手动打开的 Git 文件夹标记为“Git 文件夹”，需先明确确认启用副本管理，才参与覆盖更新。
